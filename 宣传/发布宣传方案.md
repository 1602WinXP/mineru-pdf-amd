# MinerU AMD 部署方案 — 发布宣传方案

## 一、定位

**一句话**：让每个 AMD 显卡用户都能在 2 小时内把 MinerU 部署起来，输出质量对标官网 API。

**差异化**：官方鼓励社区共同推进多卡适配，此前社区中已积累了 healy-hub 针对 2.x 的优秀探索经验。本项目以这些社区成果为基石，针对 3.x + vLLM 全新组件架构推出了一份完整 AMD 部署指南，并经过**三轮独立验证部署**：22.04+7.1.1 跑通、24.04+7.1.1 撞 LLVM 不兼容、24.04+7.2.1 跑通。每一行命令都不是想当然。

### 2.1 CSDN（技术实操向）

**标题**：MinerU 3.x AMD 显卡本地部署完整教程（三轮验证，全系 RDNA2/3/4 适用，输出质量对标官网 API）

**结构**：
1. **痛点**：MinerU 很好但 AMD 用不了？只能羡慕 N 卡用户？

5. **踩坑精华（挑 7 个最致命的）**：
   - PyTorch 2.12+ 在 WSL2 崩溃
   - hipblas.h 不能只用符号链接
   - amdsmi + 循环导入双重坑
   - uv pip 会覆盖 ROCm PyTorch
   - ninja -j20 OOM
   - CMake 4.0 拒绝 hipcc 包装器
   - Hyper-V 防火墙拦截入站
6. **效果展示**：三端对比（AMD 本地两条路径 vs NVIDIA 云端 vs 官网 API），证明质量一致

## 三、FAQ 预案

发布后可能收到的常见问题：

| 问题 | 回答 |
|------|------|
| 我的显卡 RX 6xxx 能用吗？ | RDNA2（gfx1030）理论支持，但未实测。欢迎试了提 Issue。 |
| 需要多大显存？ | 实测占用约 8.3GB，16GB 从容，12GB 够用，8GB 勉强。 |
| 和 N 卡比速度差多少？ | 差距极小。13 页 PDF 实测：<br>1. **VLM 阶段**：A10 稍快（2.18 it/s，约 5 秒）；RX 9070 紧随其后（1.98 it/s，约 6 秒）<br>2. **版面 / OCR 阶段**：RX 9070 的高带宽优势明显——路径 A 61 it/s、路径 B 65-71 it/s、A10 仅 36 it/s<br>总体耗时基本持平，输出质量完全一致 |
| 原生 Linux 怎么搞？ | 比 WSL2 简单——跳过 librocdxg 编译和 vllm 的两个 patch，其余相同 |
| 24.04 + ROCm 7.1.1 行吗？ | **不行**，LLVM 20 不兼容。24.04 必须用 ROCm 7.2.1 |
| 更新 MinerU 版本后还能用吗？ | 能，按更新指南重打 Patch 即可 |
| 为什么不用 Docker？ | ROCm 官方 Docker 镜像只覆盖服务器 GPU（Instinct 系列），消费级 RDNA 没有官方镜像 |
