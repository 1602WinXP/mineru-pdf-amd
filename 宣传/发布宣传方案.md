# MinerU AMD 部署方案 — 发布宣传方案

## 一、定位

**一句话**：让每个 AMD 显卡用户都能在 2 小时内把 MinerU 部署起来，输出质量对标官网 API。

**差异化**：官方鼓励社区共同推进多卡适配，此前社区中已积累了 healy-hub 针对 2.x 的优秀探索经验。本项目以这些社区成果为基石，推出了一份针对 3.x + vLLM 全新组件架构的完整 AMD 部署指南。

## 三、FAQ 预案

发布后可能收到的常见问题：

| 问题 | 回答 |
|------|------|
| 我的显卡 RX 6xxx 能用吗？ | RDNA2（gfx1030）理论支持，但未实测。欢迎试了提 Issue。 |
| 需要多大显存？ | 实测占用约 8.3GB，16GB 从容，12GB 够用，8GB 勉强。 |
| 和 N 卡比速度差多少？ | 差距极小。我们用 13 页的 PDF 实测对比了 RX 9070（本地）和 A10（云端）：<br>1. **VLM 阶段**：A10 稍快（2.18 it/s，约 5 秒）；RX 9070 紧随其后（1.98 it/s，约 6 秒）。<br>2. **版面/OCR 阶段**：RX 9070 的高带宽优势明显（61 it/s vs A10 的 36 it/s）。<br>总体耗时两者几乎持平，输出质量完全一致。 |
| 原生 Linux 怎么搞？ | 比 WSL2 简单——跳过第四步，其余相同。 |
| 更新 MinerU 版本后还能用吗？ | 能，按更新指南重打 Patch 即可。 |
| 为什么不用 Docker？ | ROCm 官方 Docker 镜像只覆盖服务器 GPU（Instinct 系列），RDNA 没有官方镜像。 |
